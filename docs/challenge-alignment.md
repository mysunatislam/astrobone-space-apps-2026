# Alignment with the 2026 astronaut health-monitoring challenge

AstroBone addresses [Create Health Monitoring Software for Astronauts on Space Missions](https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/) through one crew-facing flow: **Gather indicators → Evaluate changes → Act on a clear next step**. The home page makes the daily self-check the main entry; respiratory motion is an optional experimental module.

This mapping follows the challenge brief supplied by the project owner. It describes implemented behavior, not clinical effectiveness, NASA approval or an award claim.

## Demonstration and personal observations

Mission Control presents **Elena's synthetic mission**. The daily self-check separately offers **You · this device** for personal inputs. Synthetic mission values must not be described as the user's measurements. Camera-derived estimates, manually entered instrument readings, self-reports, model outputs and external research remain labeled by source.

The optional breathing module measures relative respiratory-like torso motion with a webcam or imports measured region distances from a compatible depth-camera recording. It adds a waveform, signal-quality diagnostics and optional profile-separated history. Synthetic examples cannot enter personal respiratory history, and importing one depth recording repeatedly cannot create multiple baseline readings.

Respiratory accuracy against a belt, direct depth-camera hardware capture and dense depth heatmaps remain pending. The [respiratory module and reference-validation protocol](respiratory-module.md) explains the implemented import format, quality gates and evaluation procedure. Engineering and browser tests do not establish accuracy on astronauts or clinical fitness for use. Respiratory motion does not measure bone loss.

## Scope of the submission

AstroBone is a research prototype for gathering observations, reviewing changes and preparing a human-reviewed next step. It is not a diagnostic or prescribing system. The source-derived NASA evidence is not NASA endorsement, and neither interface quality nor challenge alignment guarantees competition results. The [three-minute demonstration guide](space-apps-demo-2026.md) shows how to present the implemented workflow and its remaining validation work honestly.
