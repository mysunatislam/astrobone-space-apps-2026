# AstroBone: three-minute demonstration

Challenge: [Create Health Monitoring Software for Astronauts on Space Missions](https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/).

NASA's [2026 announcement](https://science.nasa.gov/universe/nasa-welcomes-all-ages-experience-levels-for-space-apps-challenge/) confirms registration and the November 14–15 event dates. The source was checked November 1, 2026. This project is independent; NASA datasets do not imply NASA endorsement or an award.

1. **0:00–0:30 — The mission.** Open Mission Control. Explain the synthetic astronaut and the problem: crews need to gather, evaluate and act on health information when ground support is delayed. Point to the original AstroBone logo and the on-device workflow.
2. **0:30–1:15 — Gather and check quality.** Open the breathing check. The initial rate is blank. Preview the explicitly synthetic waveform for a dependable presentation; use the actual webcam only with a visible torso and steady conditions. Explain why a refused reading is preferable to a confident invented number. Show chest/abdomen motion diagnostics and the reference-validation status.
3. **1:15–2:00 — Follow the evidence.** Open NASA evidence. Show actual group summaries from OSD-489 and measurement coverage from OSD-654, their sample counts, original files and checksums. Explain that these two new tables add 62 source rows. OSD-489 shares the RR-1 mission with the existing bone study, so it is not an independent replication. Filter the catalog to respiratory references and state which are context rather than analyzed datasets.
4. **2:00–2:40 — Evaluate a personal change.** Show the existing Self-Check and digital twin. Personal histories compare the same crew code and protocol; camera/depth measurements remain separate. Demonstrations never enter a real history. The existing clinical decision boundaries are unchanged by respiratory estimates.
5. **2:40–3:00 — What comes next.** Show the respiratory-belt comparison panel and the written protocol. State the missing evidence plainly: no belt accuracy study or depth hardware evaluation has been completed. Explain the path to participant-held-out evaluation and an analog-crew usability study.

The strongest claims are testable: source-derived NASA values, working local capture/export, explicit quality refusals, reproducible data provenance and a clear validation boundary. Describe the impact as a research objective until it is demonstrated.
